# Validation of the topology classifier

Everything here is regenerated by three scripts, run from `perovtopo/`:

```
python validation/build_validation_set.py DATA_RAW validation   # DATA_RAW holds mp_abc3.jsonl and mp_broad.jsonl (MP snapshot 2026.04.13)
python validation/run_validation.py                              # confusion matrices, misclassified lists, threshold sweeps
python validation/apply_to_generated.py POOL.jsonl.gz ...        # funnel and threshold sensitivity on generated pools
```

## Labels (independent of the classifier)

Labels come from crystal-structure prototypes (space group plus Wyckoff-site pattern from spglib, symprec 0.1) and from the
literature structure type of named compounds. The classifier is never used to assign a label. `curated_set.csv` lists every
structure with its label and the basis for it; `structures.jsonl.gz` holds the structures (Materials Project, CC BY 4.0).

* **Tier 1 (70 structures):** named compounds. 50 perovskites (ABX3 and ordered double perovskites, oxides and halides, cubic,
  tilted and polar) and 20 non-perovskites with the same stoichiometry (hexagonal 2H, post-perovskite, ilmenite, LiNbO3-type,
  hexagonal manganites, NH4CdCl3-type).
* **Tier 2 (4,270 structures), chemistry unscreened:** 3,801 prototype-defined perovskites (Pm-3m, GdFeO3-type, LaAlO3-type,
  ordered double Fm-3m) and 469 non-perovskites (post-perovskite, ilmenite, NH4CdCl3-type, 89 P6_3/mmc hexagonal polytypes with
  E_hull <= 0.1 eV/atom, and oxyanion compounds such as phosphates and borates with E_hull <= 0.1 eV/atom).

## Results

Default thresholds (b_tol 1.25, a_tol 1.3, a_min_cn 8, bx_tol 1.25), as used in the manuscript:

| Set | n | Perovskite recall | Specificity | Precision |
|---|---|---|---|---|
| Tier 1 | 70 | 48/50 = 0.96 | 20/20 = 1.00 | 1.00 |
| Tier 2 | 4,270 | 3,600/3,801 = 0.947 | 440/469 = 0.938 | 0.992 |
| Tier 2, E_hull <= 0.1 eV/atom | 2,946 | 2,374/2,513 = 0.945 | 404/433 = 0.933 | 0.988 |

With `Params(strict_corner=True)`:

| Set | n | Perovskite recall | Specificity | Precision |
|---|---|---|---|---|
| Tier 1 | 70 | 48/50 = 0.96 | 20/20 = 1.00 | 1.00 |
| Tier 2 | 4,270 | 3,600/3,801 = 0.947 | 469/469 = 1.00 | 1.00 |

**False positives (default only).** All 29 tier-2 false positives are P6_3/mmc hexagonal polytypes (for example SrMnO3, BaCrO3,
RbMgF3, RbCoF3, CsFeF3, RbNiF3). They mix corner- and face-sharing octahedra: every anion still bridges exactly two B cations and
the B-X network is three-dimensional, so the default test accepts them. The strict check rejects every one of them and changes no
perovskite call. It is therefore the more accurate definition of "corner-sharing". The manuscript counts use the default classifier
(`generated_funnel.csv` gives the effect of the strict check on the generated pools: 198 -> 196 of 3,500 for the gamma = 2 pool,
unchanged at 13 for the unconditional pool).

**False negatives (both settings).** Two tier-1 misses and 201 tier-2 misses fail one of two geometric rules:
* `CsGeI3` (R3m): the Ge2+ lone pair displaces Ge off-centre (three Ge-I bonds at 2.75 A, three at 3.35-3.43 A), so the 1.25x
  coordination shell finds only three anions and no octahedral B site is assigned.
* `NaNbO3` (R3c): the small, strongly tilted A cation has fewer than eight anions inside the 1.3x shell and is rejected as low-coordinated.
* Tier-2 misses are almost all chemically unscreened prototypes whose A cation is too small for 8-fold coordination.

The classifier is therefore conservative: it undercounts strongly distorted perovskites (lone-pair B cations, small tilted A
cations), so reported perovskite counts are lower bounds on the family size, and the default version needs the strict check to
exclude mixed-stacking polytypes.

## Threshold sensitivity (`sensitivity_sweep.csv`, `generated_sensitivity.csv`)

One threshold is varied at a time and the others stay at default (default classifier, not strict). The sweep uses all of tier 1, the 469
tier-2 negatives and a seeded random sample of 600 tier-2 perovskites, so its tier-2 recall at the default setting is 0.935 rather
than 0.947; specificity stays at 0.938 throughout because the polytype false positives do not depend on these thresholds.

| Threshold | Range | Tier-1 recall / specificity | Generated topology-positive (gamma = 2 pool, default 198) |
|---|---|---|---|
| b_tol, bx_tol | 1.05-1.50 | recall 0.86 at 1.05, plateau 0.96 from 1.20; specificity 1.00 throughout | 194 (1.15), 197 (1.20), 198 (1.25-1.40) |
| a_tol | 1.1-1.7 | recall 0.56 at 1.1, 0.92 at 1.2, 0.96 at 1.3, 0.98 at 1.4-1.7; specificity 0.90 at 1.7 | 193 (1.2), 198 (1.3), 201 (1.4), 207 (1.5) |
| a_min_cn | 6-12 | recall 0.98 at 6 (specificity 0.90), 0.96 at 7-8, 0.74 at 9, 0.56 at 12 | 231 (6), 202 (7), 198 (8), 194 (9), 191 (10) |

The mixed-B fraction among topology-positive structures stays between 0.64 and 0.68 across all settings. The two thresholds
that matter are the A-site rules (a_tol, a_min_cn); the B-site coordination and bridging tolerances are stable above 1.20.
The headline counts (458 stoichiometry-compatible, 198 topology-positive of 3,500) are reproduced exactly by this package.
